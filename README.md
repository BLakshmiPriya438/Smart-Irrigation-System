# Smart Irrigation System

## Overview
This project is an IoT-based Smart Irrigation System developed using Arduino UNO. It automatically controls a water pump based on soil moisture levels.
## Components Used
- Arduino UNO
- Soil Moisture Sensor
- Relay Module
- Water Pump (DC Motor)
- LED
- Jumper Wires
## Technologies Used
- Embedded C
- Arduino IDE
## Features
- Automatic irrigation
- Soil moisture monitoring
- Automatic pump control
- LED status indication
## Working
The soil moisture sensor continuously measures the moisture level. When the soil becomes dry, the Arduino activates the relay to turn ON the water pump. Once the soil has sufficient moisture, the relay switches OFF the pump automatically.
